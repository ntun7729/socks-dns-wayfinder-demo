## Question

What exact SOCKS5 and DNS behavior should the prototype expose?

The answer must define supported SOCKS5 commands and address types, authentication behavior, whether domain names are resolved at the server, how DNS queries are carried and answered, UDP versus TCP policy, timeouts, maximum frame sizes, and failure semantics. It must define a local operating mode that is useful without TUN/TAP while avoiding a claim of transparent system-wide VPN routing.
